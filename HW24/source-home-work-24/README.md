/*--                            Начало работы                         --*/

1   Для выполнения использовать уже предоставленный файл index.html, 
    который находится внутри этой папки.
    В нём уже подключены шрифты для текста.
2   Изучить все разделы этого документа.


/*--                            Цвета для таблицы                     --*/

1   Фон:                         style="background-color: #eddaff;"
2   Ячейка «клиент» и «штрих-код»:   style="background-color: #c2b3d1;"
3   Заголовок таблицы:           style="background-color: #310062;"


/*--                          Дополнительные атрибуты                 --*/

1   Высота: height="20"  
    Нужен для увеличения высоты ячеек. Значение указываем без приставки px, 
    просто цифрами, как в примере ="20".

2   Внешний отступ от верхней таблицы вниз:
    style="margin-top:20px;"
    Устанавливается к тегу <table>, и таблица опустится вниз 
    на то количество пикселей, которое указано.
    В данном случае приставка px обязательна!


/*--                          Дополнительная информация               --*/

1   Арабские цифры не нужно писать — их в структуре нет. 
    Они выполнены через CSS как декоративный элемент,
    как и центральная линия между таблицами.
